# gains
A calculator to see how much you've made off of Bitcoin investments

---

After the recent dips and rises in the market, I thought it would be cool to have a calculator to see how much I've earned and lost (mostly earned 😉 )

Anyway, there are a myriad of little programs out there that do this, but I thought it would be a good project to deal with some APIs, simple calculations, and functions in Python.

---

IMPORTANT: You'll need to an API key from [CryptoCompare](https://www.cryptocompare.com/cryptopian/api-keys) for the program to work. Once you've created an account, go to your profile/settings and set up a key; it's super easy. After that, the easiest way to get up and running is to replace line 8 with `API_KEY = 'whatever-your-key-is'`. If you want to put the key in your `.env` file, you can do that too. But that might mean you need to install `python-dotenv` first. Up to you.
